# Demo tracks

Four fixed chiptune/glitch tracks bundled for testing the visualizer with no
live audio input. Generated once by `tools/gen_demo_tracks.py` (deterministic
— same seed, same output) and committed as fixtures. They don't change per run.

| File | Vibe | BPM | Length |
|------|------|-----|--------|
| demo-01-overworld-run.ogg | Cheerful chiptune, C major. Square lead, triangle bass, four-on-the-floor. | 140 | 28s |
| demo-02-boss-protocol.ogg | Aggressive boss theme, A minor. Driving 16th bass, stab lead, double-kick feel. | 160 | 25s |
| demo-03-glitch-machine.ogg | Glitch chip. Tritone bass, bitcrushed blips, stutter edits, broken drums. | 128 | 31s |
| demo-04-title-screen.ogg | Dreamy title screen. Detuned pads, slow arps, sparse lead, soft drums. | 92 | 43s |

Demo mode in the app: pick any of these from a selector, no mic/line-in needed.
